      本产品把管理器内置进自己的 APK，应用包名为 com.youlong.hd。
      随之改写的应用级标识符：

        应用包名 / applicationId        : com.youlong.hd
        管理器 Provider authority        : com.youlong.hd.stellar
        REQUEST_PERMISSION action        : com.youlong.hd.intent.action.REQUEST_PERMISSION
        binder extra key                 : com.youlong.hd.intent.extra.BINDER
        client binder extra key          : com.youlong.hd.intent.extra.CLIENT_BINDER
        日志回传 Provider authority      : com.youlong.hd.stellar
        FileProvider authority（管理器） : com.youlong.hd.stellar.fileprovider
        StellarHelper 管理器包名         : com.youlong.hd
        开机脚本 pm path 包名            : com.youlong.hd

      ⚠️ Java/Kotlin 包名 roro.stellar.* / com.stellar.* / moe.shizuku.*
         一律**保持上游原名不变**。原因有二：
           · 原生启动器与 JNI 按硬编码类名工作 ——
             starter.cpp 用 CLASSPATH 加载 roro.stellar.server.StellarService，
             adb_pairing.cpp 用 FindClass("roro/stellar/manager/adb/PairingContext")
             注册 native 方法；
           · 宿主用类名字符串启动管理器界面。

  (B) 构建配置适配（manager 由 application 降级为 library）
        · embedded/manager/build.gradle：
            插件 com.android.application → com.android.library；
            删除 applicationId / versionCode / versionName / signingConfigs /
            applicationVariants 输出改名等 application 专属配置；
            删除 externalNativeBuild 与 prefab（原生部分移到 :app 统一构建）；
            删除 collapseReleaseResourceNames 与 CompileArtProfileTask 关闭逻辑；
            删除 dev.rikka.tools.autoresconfig 插件（该插件要求 application
            扩展，且它生成的 StellarLocales 在全部源码中均无引用）。
        · embedded/manager/src/main/AndroidManifest.xml：
            删除 android:sharedUserId（上游作为独立 APK 时使用，库模块不允许）；
            FileProvider authority 改为 ${applicationId}.stellar.fileprovider
            （与宿主已有的 ${applicationId}.fileprovider 冲突）。

  (C) 宿主导入点适配（管理器不再由系统实例化）
        · StellarApplication.kt：
            `application` 的类型由 StellarApplication 放宽为 Application；
            init(context) 由 private 改为 public；
            新增 attachApplication(Application) 供宿主赋值。
            上游这三件事由系统调用 onCreate() 完成，本产品改为由
            com.youlong.hd.YouLongApp 显式调用（YouLongApp 顶部有说明）。
        · 宿主 YouLongApp.java 相应新增对 StellarApplication 的初始化调用。
